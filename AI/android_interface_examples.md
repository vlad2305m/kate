# Android Interface Examples: KTrip and Elisa

## Overview

Both KTrip and Elisa are KDE applications that support both desktop (Linux/macOS/Windows) and Android.
They are both built with Qt6/KDE Frameworks 6 and use the same CMake-based build system as Kate.

---

## KTrip Android Implementation

KTrip is a public transport journey planner using QML/Kirigami UI.

### Directory Structure
```
ktrip/
├── android/
│   ├── AndroidManifest.xml
│   ├── build.gradle
│   ├── res/
│   │   ├── drawable/
│   │   │   ├── ktrip.png        (app icon for splash)
│   │   │   ├── splash.xml       (layer-list referencing ktrip.png)
│   │   │   ├── ic_launcher_background.xml  (vector background for adaptive icon)
│   │   │   └── ic_launcher_foreground.xml  (vector foreground for adaptive icon)
│   │   └── mipmap-{hdpi,mdpi,xhdpi,xxhdpi,xxxhdpi,anydpi-v26}/
│   │       └── ic_launcher.{png,xml}
└── src/CMakeLists.txt
```

### CMakeLists.txt (root): Key Android inclusions
```cmake
include(ECMAddAndroidApk)

if (ANDROID)
    find_package(Qt6 ${QT_MIN_VERSION} REQUIRED COMPONENTS Svg)
    find_package(KF6 ${KF_MIN_VERSION} REQUIRED COMPONENTS Kirigami)
    find_package(OpenSSL REQUIRED)
else()
    find_package(Qt6 ${QT_MIN_VERSION} REQUIRED COMPONENTS Widgets)
    find_package(KF6 ${KF_MIN_VERSION} REQUIRED COMPONENTS QQC2DesktopStyle Crash)
endif()
```

### src/CMakeLists.txt: Android-specific
```cmake
if (ANDROID)
    target_link_libraries(ktrip PRIVATE
        KF6::Kirigami Qt::Svg OpenSSL::SSL
    )
    kirigami_package_breeze_icons(ICONS ...)
    ecm_add_android_apk(ktrip ANDROID_DIR ${CMAKE_SOURCE_DIR}/android)
else()
    target_link_libraries(ktrip PRIVATE Qt::Widgets KF6::Crash)
endif()
```

### AndroidManifest.xml: Standard Qt-for-Android manifest
- Package: `org.kde.ktrip`
- Activity: `org.qtproject.qt.android.bindings.QtActivity`
- meta-data: `android.app.lib_name` = `ktrip` (matches the executable/shared lib name)
- Template placeholders: `%%BUNDLE_LOCAL_QT_LIBS%%`, `%%INSERT_LOCAL_LIBS%%` etc.

### build.gradle: Standard Qt/Android build
- `apply from: '../ecm-version.gradle'` (provided by ECM)
- Java source compatibility: VERSION_1_8
- `applicationId "org.kde.ktrip"`
- `packagingOptions` excludes unused Qt modules

## Elisa Android Implementation

Elisa is a music player with QML/Kirigami UI, significantly more complex than KTrip.

### Directory Structure
```
elisa/
├── android/
│   ├── AndroidManifest.xml
│   ├── build.gradle
│   ├── gradle.properties
│   ├── version.gradle.in        (CMake-configured file)
│   ├── src/org/kde/elisa/       (Java source files for Android-specific features)
│   │   ├── ElisaActivity.java
│   │   ├── ElisaService.java    (media playback foreground service)
│   │   ├── Player.java
│   │   ├── FileListing.java
│   │   └── CoverImageProvider.java
│   └── res/
│       ├── drawable/
│       │   └── splash.xml
│       └── mipmap-{hdpi,mdpi,xhdpi,xxhdpi,xxxhdpi,anydpi-v26}/
│           └── ic_launcher{,_background,_foreground,_monochrome}.png
└── CMakeLists.txt
```

### CMakeLists.txt (root): Android vs Desktop
```cmake
include(ECMAddAndroidApk)

if (NOT WIN32 AND NOT ANDROID)
    find_package(Qt6DBus ...)
    find_package(KF6DBusAddons ...)
endif()

if (ANDROID)
    find_package(Qt6 ... REQUIRED COMPONENTS CorePrivate)
    find_package(KF6Kirigami ...)
else()
    find_package(KF6KIO ...)
    find_package(KF6QQC2DesktopStyle ...)
endif()

if (ANDROID)
    configure_file(${CMAKE_CURRENT_SOURCE_DIR}/android/version.gradle.in
                   ${CMAKE_BINARY_DIR}/version.gradle)
endif()
```

### src/CMakeLists.txt: Android-specific sources
```cmake
if (ANDROID)
    set(elisaLib_SOURCES
        ${elisaLib_SOURCES}
        android/androidcoverimageprovider.cpp
        android/androidmusiclistener.cpp
        android/androidfilelisting.cpp
        android/androidplayer.cpp
        android/androidplayerjni.cpp
    )
endif()

# ...
if (ANDROID)
    target_link_libraries(elisaLib PRIVATE Qt6::CorePrivate Qt6::Quick jnigraphics)
endif()

# ...
if (ANDROID)
    target_link_libraries(elisa PRIVATE Qt::Svg Qt::Sql Qt::Concurrent KF6::Kirigami Qt6::CorePrivate)
    kirigami_package_breeze_icons(ICONS ...)
    ecm_add_android_apk(elisa ANDROID_DIR ${CMAKE_SOURCE_DIR}/android)
endif()
```

### version.gradle.in: CMake-configured version file
```groovy
// CMake substitutes @PROJECT_VERSION@ with the actual version
ext { projectVersionFull = "@PROJECT_VERSION@" }
```

### build.gradle: More complex, uses Kotlin + AndroidX
- Uses Kotlin plugin for Java interop
- `apply from: '../version.gradle'` (generated by CMake from version.gradle.in)
- Java compatibility: VERSION_11
- Additional dependencies: `androidx.media:media`, `androidx.appcompat:appcompat`

### gradle.properties:
```properties
android.useAndroidX=true
org.gradle.jvmargs=-Xmx2500m ...
```

## Key Patterns for Kate Android Support

### 1. `ECMAddAndroidApk` CMake module
Both apps use `include(ECMAddAndroidApk)` in the root CMakeLists.txt and call
`ecm_add_android_apk(<target> ANDROID_DIR ${CMAKE_SOURCE_DIR}/android)` in the app's CMakeLists.

### 2. Android-specific dependency conditional
```cmake
if (ANDROID)
    # runtime deps become build-time deps; skip desktop-only features
else()
    # desktop-specific: KF6::Crash, KF6::QQC2DesktopStyle, KIO, DBus, etc.
endif()
```

### 3. android/ directory with standard Qt-for-Android files
- `AndroidManifest.xml`: declares app package, activity, `lib_name` meta-data
- `build.gradle`: Android build configuration
- `res/`: mipmap icons and splash screen

### 4. Differences relevant to Kate (vs KTrip/Elisa)
Kate uses Qt Widgets (not QML/Kirigami), which is fully supported on Android via Qt6.
Kate-specific differences:
- **No Kirigami dependency**: Kate uses `Qt::Widgets` → `QApplication` on Android instead
- **No QML modules to package**: `kirigami_package_breeze_icons` not needed
- **KCrash**: Must be made optional on Android (KTrip/Elisa don't use KCrash at all)
- **libintl**: Must be skipped on Android (KTrip/Elisa don't use it)
- **DBus**: Already conditionally compiled out on Android
- **SingleApplication**: Already handles Android gracefully (no-op)
- **KWrite is simpler**: KWrite (single-window text editor) is a better candidate for
  an initial Android APK than the full Kate multi-window IDE
